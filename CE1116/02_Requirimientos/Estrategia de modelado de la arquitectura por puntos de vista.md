## 📚 Idea/Concepto 
La estrategia de modelado por puntos de vista en arquitectura se trata de usar viewpoints para dividir y realizar una descripción del sistema según las principales preocupaciones que puede tener cada stakeholder. Se define una view concreta usando un par de reglas, notaciones, buenas practicas, de manera que así se pueda ver el sistema desde distintos ángulos. Esto permite resolver trade-offs entre requisitos de calidad como seguridad o disponibilidad. Es posible reutilizar viewpoints como plantillas de manera que la información no se pierda.
