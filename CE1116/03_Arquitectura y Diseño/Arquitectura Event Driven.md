## 📚 Idea/Concepto 

La arquitectura Event Driven es una forma de diseñar sistemas donde los módulos reaccionan a eventos, que son hechos registrados de manera inmutable y distribuidos de forma asíncrona. El manejo de eventos se realiza usando mecanismos como brokers, mediadores o el patrón Pub/Sub, lo que permite a los componentes estar desacoplados y trabajar de manera independiente. Además, los procesadores de eventos deben ser idempotentes para asegurar robustez ante reintentos y duplicados. Este enfoque facilita la flexibilidad, la escalabilidad y la recuperación usando el historial de eventos.
