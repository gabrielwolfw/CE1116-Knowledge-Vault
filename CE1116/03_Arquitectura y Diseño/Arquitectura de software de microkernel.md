## 📚 Idea/Concepto 

La arquitectura de microkernel separa la funcionalidad mínima en un núcleo sencillo y utiliza plug-ins registrados para agregar y aislar código altamente volátil o especializado. Esto mantiene el sistema monolítico pero fácil de extender, probar y mantener, ya que los plug-ins exponen contratos claros para integrarse con el núcleo.
