## 📚 Idea/Concepto 

**La arquitectura en capas es una manera de estructurar el software dividiéndolo en niveles donde cada capa tiene responsabilidades específicas. Las capas interactúan a través de interfaces definidas, lo que facilita el mantenimiento, las pruebas y futuras modificaciones del sistema. Esta estructura suele separar la interfaz de usuario, la lógica de negocio y el acceso a datos, ayudando a que cada parte se pueda modificar sin afectar las demás. Es importante distinguir las capas lógicas, que agrupan funciones dentro del código, de las capas físicas, que se relacionan con cómo el sistema se despliega en los servidores. Además, las reglas de interacción pueden ser estrictas o flexibles según las necesidades del proyecto. El principio base es la separación de responsabilidades, que permite que el sistema sea más ordenado y sencillo de evolucionar.**
