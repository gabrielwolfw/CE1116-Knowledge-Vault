## 📚 Idea/Concepto 


Se define como una arquitectura que realiza una combinación de recursos de una nube pública y de un entorno on-premise, haciendo posible  que las cargas de trabajo se repartan y se integren a las necesidades del negocio, pero introduce una mayor complejidad operativa y desafíos en DevOps por la gestión y portabilidad entre los entornos. El cloud híbrido brinda un punto de equilibrio entre flexibilidad y escalabilidad, al mismo tiempo que mantiene el control y personalización de los sistemas locales, siendo especialmente útil cuando ciertos datos deben permanecer on-premise por requisitos regulatorios o de cumplimiento. Para que las aplicaciones sean realmente portables en ambos entornos, el modelo híbrido necesita una plataforma estandarizada, como contenedores, Kubernetes y es clave mantener una base operativa consistente, como el mismo sistema operativo o la misma tecnología de contenedores, para evitar fragmentación y facilitar la integración efectiva entre ambos mundos.
