## 📚 Idea/Concepto 


Una Public IP en un entorno cloud dónde el enfoque es proporcionar una comunicación directa con el internet mediante dirección IP global que permite que los recursos desplegados, como instancias de cómputo o servicios gestionados.  Dentro de un ambiente de public IP existen dos tipos de soluciones. Primero, las IPs estáticas, que mantienen un valor fijo y se reservan para escenarios donde se requiere una referencia permanente o integraciones que dependan de un direccionamiento constante. Por otro lado, las IPs dinámicas, cuyo valor puede variar durante el ciclo de vida del recurso. La selección entre una IP estática o dinámica es dependiendo del tipo de servicio y de los requisitos operativos asociados. La asignación de una IP pública debe complementarse con controles de seguridad mediante Network Security Groups, los cuales permiten definir reglas para limitar puertos y protocolos específicos, asegurando la protección del recurso frente a accesos no autorizados o amenazas externas.
